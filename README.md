# ⚡ GridForge

**GridForge** is a modular, extensible power system simulation framework designed for advanced grid analysis, protection studies, and dynamic stability evaluation.

It is built with a focus on **engineering accuracy**, **clear architecture**, and **scalability**, resembling the workflow of industry tools like PSS®E, DIgSILENT PowerFactory, and ETAP.

---

## 🚀 Features

### 🟢 Core Power System Analysis
- Per-unit system modeling
- Y-Bus matrix formation
- Newton-Raphson load flow solver
- Line and transformer power flow calculation

### ⚡ Fault & Short Circuit Analysis
- 3-phase symmetrical faults
- Unsymmetrical faults (SLG, LL, DLG)
- Sequence network modeling (positive, negative, zero)
- Fault current and bus voltage calculation

### 🔌 Protection System Modeling
- Overcurrent relays (IDMT curves)
- Distance protection (Zone 1, 2, 3)
- Relay coordination with grading
- Breaker tripping logic and system isolation

### 🔁 Contingency Analysis
- N-1 line/generator outage simulation
- Automatic system reconfiguration
- Post-contingency load flow validation

### 🌀 Dynamic & Stability Analysis
- Swing equation solver
- Multi-machine transient stability
- Fault-on and post-fault simulation
- Critical clearing time (CCT) evaluation
- Generator subtransient modeling

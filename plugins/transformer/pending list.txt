Layer: Plugin Layer

Baseline: GridForge Model Layer V2

## 1. Transformer Plugin Attachment / Registration

**Status:** PENDING

Determine how transformer plugins are attached to a
`core.model.transformer.Transformer`.

Current plugins are independent objects and receive a reference to
the core transformer.

Need to establish a formal mechanism for:

* Plugin registration.
* Plugin discovery.
* Plugin lookup.
* Plugin lifecycle.
* Duplicate-plugin prevention.
* Plugin removal/replacement.
* Plugin validation.
* Serialization/deserialization.

Do not modify `core/model/transformer.py` until the architecture
requires it.

## 2. Transformer Plugin Container

**Status:** PENDING

Determine whether transformer-specific capabilities should remain
independent:

```text
Transformer
├── Winding
├── VectorGroup
├── Grounding
├── TapChanger
└── TransformerEquivalent
```

or whether a dedicated transformer plugin/container should coordinate
these capabilities:

```text
Transformer
└── TransformerPluginContainer
    ├── Winding
    ├── VectorGroup
    ├── Grounding
    ├── TapChanger
    └── TransformerEquivalent
```

Preferred direction:

* Keep individual capabilities independent.
* Introduce a container only if lifecycle/coordination requirements
  genuinely justify it.

## 19. Plugin Validation

**Status:** PARTIALLY IMPLEMENTED

Current plugins perform local validation.

Need a future distinction between:

### Local validation

Examples:

* Positive voltage.
* Valid tap range.
* Valid impedance.
* Valid grounding resistance.

### System validation

Examples:

* Winding actually exists.
* Vector group matches winding configuration.
* Grounding references a valid neutral.
* Tap changer applies to the correct winding.
* Plugin does not conflict with another plugin.

System validation must not be duplicated inside individual plugins.

---

# Architectural Rule

Do not move detailed transformer physics back into `core/model/`
merely because a new capability is required.

Preferred architecture:

```text
                    GridForge Core
                         │
                  core/model/
                         │
              ┌──────────┴──────────┐
              │                     │
        Transformer             Branch
              │
              │ stable interface
              ▼
       plugins/transformer/
              │
       ┌──────┼────────┬────────┐
       ▼      ▼        ▼        ▼
    Winding  Vector   Grounding TapChanger
             Group
              │
              ▼
          Equivalent
```

The core model remains small and stable; specialized transformer
physics is progressively added through capabilities/plugins.

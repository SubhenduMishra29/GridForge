## Deferred / blocked scope

- No CI, test suite, or application runtime was executed.
- Timer first-sample semantics remain unchanged pending explicit engineering/product semantics.
- Contactor, actuator, generator-output, and plant-controller-output action commands are not invented; the canonical target contract can represent them, while Application dispatch rejects target classes without an actual command contract.
- Protection-to-equipment target resolution remains an Application configuration responsibility; Protection does not infer or own the physical target.
